# FOODZY — MASTER FIGMA MAKE PROMPT (PART 1)

## Project Overview

**Project Name:** FOODZY

**Industry:** Food Delivery Platform

**Target Audience:** Residents of Tier-3 cities, district headquarters, tehsil towns, villages, and semi-urban regions across India.

**Primary Objective:**

Design a premium, mobile-first, highly interactive website for FOODZY that builds trust, showcases restaurants and services, encourages users to download the FOODZY mobile app, attracts restaurant partners, and provides dedicated login portals for restaurants, delivery partners, and administrators.

This is **not** an online ordering website. Customers can search restaurants and browse menus, but all ordering is completed in the FOODZY mobile app.

The final website should look like it has been designed by one of the world's best digital product agencies.

# Design System Rules for Dashboards

* Use a consistent 8px spacing system.
* Rounded corners (20–24px) throughout.
* Glassmorphism only for overlays, dialogs, and key summary cards.
* Smooth page transitions with subtle fade and slide animations.
* Skeleton loaders for all asynchronous data.
* Empty states should include friendly illustrations and clear CTAs.
* Success, warning, and error states must use tasteful motion and color.
* All forms should support inline validation and contextual help.
* Every page must be optimized for keyboard navigation and accessibility.
* Every UI element should be created as a reusable Auto Layout component with variants and design tokens.
